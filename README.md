# Dear Future Me — The Memory Universe 💜💗

A frontend-only React mini project with a dreamy lavender, blush-pink and midnight-plum theme.

## Requirements
- Node.js (LTS recommended)
- VS Code or another code editor

## Run locally
1. Extract the ZIP.
2. Open the `dear-future-me` folder in VS Code.
3. Open Terminal in VS Code.
4. Run `npm install`
5. Run `npm run dev`
6. Open the local URL printed in the terminal (usually `http://localhost:5173`).

## Features
- Animated interactive memory constellation
- Time capsules with mood, letter, photo, opening date and countdown
- Memory Garden with mood filters and diary flowers
- Sealed Memory Cards: letters and photos are not previewed on cards before the opening date
- Opening-day letter reveal and Then & Now reflection
- Daily Feelings Diary: good news, hard things, lessons, gratitude, mood, date and optional photo
- Ask Your Future Self: daily prompt answers sealed for one month, three months, six months or a year
- Future Self Quiz: save personal predictions and revisit them later to compare with real life
- Life Timeline showing capsules, diary pages and future-self answers
- Responsive layout and blush-pink accents throughout
- LocalStorage persistence; no backend required

## Storage and privacy notes
- Data stays in the current browser on the current device. It does not sync or back up automatically.
- Photos should be kept small to avoid filling browser storage.
- Date locks are a frontend experience, not secure encryption. A user can inspect or change browser storage and app code.
- Clearing browser site data can delete saved memories, so keep your own backups of anything important.
- Google Fonts are loaded online; system fonts are used if they cannot load.
